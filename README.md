# Проекты по статистическим методам обработки данных

## 1. Критерии согласия

Программа проверяет гипотезы о законе распределения с использованием трёх критериев: хи-квадрат Пирсона, Колмогорова-Смирнова и Андерсона-Дарлинга. Генерируются выборки разных объёмов (от 10 до 5000) из нескольких распределений (нормальное, равномерное, экспоненциальное, Стьюдента, логнормальное, бета, Вейбулла). Для каждого распределения и объёма выборки выполняется 10 реализаций, подсчитывается частота верных и неверных срабатываний критериев. Визуализируются плотности, эмпирические функции распределения и Q-Q графики.

**Ключевые функции:**
- `chi_square_test()` – расчёт p-value для критерия хи-квадрат
- `ks_test()` – критерий Колмогорова-Смирнова
- `anderson_test()` – критерий Андерсона-Дарлинга
- `generate_data()` – генерация данных из заданного распределения
- `plot_distributions_comparison()` – визуализация сравнения распределений

---

## 2. Двухвыборочные критерии однородности

Программа сравнивает две выборки (оценки двух студентов) с помощью пяти критериев: Колмогорова-Смирнова, омега-квадрат (Андерсона-Дарлинга), Манна-Уитни, хи-квадрат (с разным числом интервалов), критерия знаков и Уилкоксона. Выборки имеют объём 76, оценки по пятибалльной шкале. Программа выводит описательные статистики, результаты каждого критерия с p-value и выводом о принятии или отвержении гипотезы однородности. Также демонстрируется влияние числа интервалов в критерии хи-квадрат на результат.

**Ключевые функции:**
- `ks_2samp()` – сравнение эмпирических функций распределения
- `anderson_ksamp()` – проверка принадлежности выборок одному распределению
- `mannwhitneyu()` – сравнение медиан независимых выборок
- `chi2_contingency()` – проверка независимости признаков
- `binomtest()` и `wilcoxon()` – критерии для связанных выборок

## 3. Коэффициенты корреляции

Программа генерирует две независимые выборки X ~ N(0,1) и Z ~ N(5,2) объёмом 1000. Строятся три типа зависимостей: линейная (Y = aX + (1-a)Z для a = 0, 0.25, 0.5, 0.75, 1), кубическая (Y = 0.05X³ + 4Z) и квадратичная (Y = X² + Z). Для каждой зависимости рассчитываются коэффициенты корреляции Пирсона, Спирмена и Кендалла, проверяется гипотеза о равенстве коэффициента нулю на уровне α = 0.05. Также демонстрируется влияние выбросов (1% точек, сдвиг на +30 для линейной и +100 для кубической зависимости) на все три коэффициента.

**Ключевые функции:**
- `pearsonr()` – коэффициент линейной корреляции
- `spearmanr()` – ранговый коэффициент корреляции
- `kendalltau()` – коэффициент корреляции Кендалла
- Визуализация scatter plot для всех зависимостей

## 4. Дисперсионный анализ (ANOVA)

Программа анализирует четыре набора данных по три группы по 30 наблюдений в каждой. Первый набор – разные средние (10, 12, 14) при равных дисперсиях. Второй – разные средние (10, 11, 12) при разных дисперсиях (1, 3, 5). Третий – одинаковые средние (0, 0, 0). Четвёртый – первый набор с добавленными выбросами. Для каждого набора применяются три критерия: параметрический критерий Фишера, непараметрический критерий Краскела-Уоллиса и критерий Джонкхиера для обнаружения монотонного тренда. Делаются выводы о чувствительности критериев к нарушению предпосылок и к выбросам.

**Ключевые функции:**
- `f_oneway()` – однофакторный дисперсионный анализ
- `kruskal()` – непараметрический аналог ANOVA
- `jonckheere_test()` – ручная реализация критерия Джонкхиера
- Визуализация boxplot для всех групп

## 5. Критерии случайности временных рядов

Программа генерирует пять временных рядов объёмом 100: белый шум, слабый положительный тренд (+0.01 на шаг), сильный отрицательный тренд (-0.5 на шаг), синусоидальную волну с шумом и белый шум с одним выбросом (значение 50 на позиции 50). Для каждого ряда применяются четыре непараметрических критерия проверки случайности: критерий инверсий, сериальный критерий Вальда-Вольфовица, критерий Рамачандрана-Ранганатана и критерий серий знаков первых разностей. Результаты выводятся в таблице с p-value и выводами, строится визуализация всех пяти рядов.

**Ключевые функции:**
- `inversion_test()` – критерий, основанный на числе инверсий
- `wald_wolfowitz_test()` – критерий, основанный на числе серий относительно медианы
- `ramachandran_rangarajan_test()` – учитывает длины серий
- `sign_series_test()` – критерий серий знаков первых разностей

## 6. Двухфакторный дисперсионный анализ

Программа анализирует данные с двумя факторами: главный фактор A (4 уровня) и мешающий фактор B (8 уровней). Рассматриваются четыре сценария: нормальные данные с влиянием A и B, нормальные данные с сильным влиянием B, данные с распределением Лапласа и выбросом, данные с нулевым влиянием A. Применяются критерий Фридмана (непараметрический аналог двухфакторного ANOVA), критерий Пейджа (для обнаружения упорядоченного тренда), двухфакторный ANOVA и однофакторный ANOVA (для демонстрации важности учёта блоков). Сравниваются p-value всех критериев на логарифмической шкале.

**Ключевые функции:**
- `friedmanchisquare()` – критерий Фридмана
- `page_trend_test()` – критерий Пейджа
- `ols()` и `anova_lm()` – построение линейной модели и ANOVA
